# Blog posts

Each `.md` file in this folder is a post. The file name is the URL slug:
`my-post.md` → `/blog/my-post/`. This README is not a post.

```md
---
title: "Post title"
excerpt: "One or two sentences for the list page."
author: "MasterFabric Team"
publishDate: "2026-10-29"
category: "AI Engineering"
tags: [claude-code, sdlc]
---

A paragraph.

## A heading

- A list item

> A quote

    (code blocks use ``` fences)
```

Supported in the body: paragraphs, `##` headings, `-` lists, `>` quotes and fenced code blocks.
